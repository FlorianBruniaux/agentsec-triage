## Reviewed claim scope

### Overpatch sandbox write-boundary escape

- ID: `review-2026-09-advisory-codex-2026-001`
- Publisher: Accomplish AI
- URL: <https://www.accomplish.ai/blog/escaping-the-openai-codex-sandbox-twice/>
- Supports:
  - Accomplish reported that attacker-controlled patch paths could expand write authorization beyond the Codex workspace. The researcher identifies CLI 0.149.0 as fixed.
  - Reviewed remediation: Update Codex CLI to 0.149.0 or later.
  - Accomplish reported that a Desktop-installed JavaScript helper exposed a privileged trust token within shared memory, enabling host execution even in read-only mode. The researcher identifies Desktop build 26.818.21641 as fixed.
  - Reviewed remediation: Update Codex Desktop to build 26.818.21641 or later; a CLI-only update does not establish that the Desktop helper is patched.

### Plugin4Shell plugin pin verification bypass

- ID: `review-2026-09-advisory-plugin4shell-2026-001`
- Publisher: AIR Security
- URL: <https://www.air.security/blog-posts/plugin4shell>
- Supports:
  - AIR reports plugin checkout can resolve an attacker-controlled default branch instead of the reviewed commit. The SHA-shaped branch variant depends on Git host rules; Gemini uses a FETCH_HEAD variant.
  - Reviewed remediation: AIR reports fixes in Claude Code 2.1.179 and Codex 0.146.0. For other affected installers, verify current vendor guidance or disable affected plugin updates.
